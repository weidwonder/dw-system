# 协作面 = solo

> 加载条件：无其他人类协作方时加载。
> 本文按 RFC 2119 解释 MUST / MUST NOT / SHOULD / MAY。
> 本文只管**因为没有别人**才发生变化的约定。它裁掉的是**对齐开销**，MUST NOT 被读成"流程可以放松"——真正会伤到你的那几道门，恰恰在没人兜底时更重要（§4）。

## 1. 可跳步：Step 2 / Step 3 通常省略

- **Step 3（PRD 细澄清）与 Step 2（Overview）MAY 省略**——你既是产品又是技术，没有协作方要对齐，写 Overview 的主要收益（让别人建立同一心智模型）不存在。
  - **这条 MAY 以"本次分流未被能力位上调"为前提**：探测到权威位时，跨仓 / 影响面说不清的改动 **MUST 倾向升级**到 Step 2 出 Overview（`capability/curated.md` §1 分流默认假设），此时本条 MAY **不适用**，MUST NOT 用它抵掉升级。判据冲突时以能力位为准（本文 §5），因为分流默认假设不由协作面决定。
- 但以下情况 SHOULD 照写 Overview，收益方是**两个月后的你自己**和**零上下文的 agent**：
  - 复杂到"两周后自己都看不懂当初为什么这么写"；
  - 改动跨多个模块 / 限界上下文，影响面自己都说不清；
  - 打算把执行拆给多个 agent 会话做——Overview 是它们之间唯一的通信信道。

> **省略的是"对齐用的文档"，不是"决策记录"。** 已定决策照样 MUST 落盘（写进 Lean Change Spec 或 spec 的决策表），否则下一个会话无从继承。

## 2. 不需要 owner 对齐、不需要评审会

- 项目里不存在"别人的仓"，**MUST NOT 向不存在的 owner 求证**，也 MUST NOT 因"等待 owner 确认"而挂起任务。跨仓改动只需自己按依赖顺序排合并次序（顺序规则在 `core/`）。
- **MUST NOT 开评审会**这类等待人类到场的动作。需要第二意见时走子代理（§4）。

## 3. 用户既是产品又是技术

本协作面下的"用户"就是开发者本人，因此：

- **MUST NOT 对用户隐藏技术细节。** 团队场景里"不得要求业务用户理解技术方案后拍板"的保护在这里不适用——用户有能力也有必要看到技术取舍。
- 仍然 MUST NOT 用技术细节淹没业务判断：先说业务影响，再给技术理由，让用户能快速拍板（`core/用户沟通纪律.md`）。
- **兼容取舍每次由你拍板。** AI **MUST NOT 默认兼容**。单人项目最容易"顺手就把旧行为砍了"，然后被自己两个月前造的数据打脸；每次照样把被改变的既有行为逐条列出，自己明确拍板一次。被新逻辑取代的旧函数/文件/配置/开关当场删除，不留"以后可能用"；保留项 MUST 带理由与到期日。

## 4. 代码评审门 MUST NOT 省略

**没有同事帮你看，子代理就是你唯一的第二双眼睛。**

- 每次编码后 MUST 过代码评审门（`core/代码评审纪律.md`）。Lean 改动派 1 个子代理跑三轴精简版即可，但**不能跳过**。
- 这一条不因"改动很小""就我一个人用"而豁免。团队里 PR 上有别人的眼睛，solo 项目里没有——把这道门省掉，等于整条链路上没有任何人复核过 AI 的产出。
- P0/P1 修完才收工。Agentic 项目增派一个加载 `agentic-principle` 的 agent 架构轴。

## 5. 分流默认假设不由本文决定

"默认走 Lean"还是"影响面不清时宁可升级"，由**能力位**决定（见 `capability/curated.md` §1 与 `core/00-流程总纲.md`），**MUST NOT** 从"只有我一个人"推出"默认走最短流程"。一个人维护的十万行遗留系统，默认走 Lean 是危险的。

## 6. 与其它分册的边界

| 想找的东西 | 在哪 |
|---|---|
| 六条"不裁剪"护栏（目录 / 沟通 / worktree / 评审门 / 兼容 / 测试） | `core/00-流程总纲.md` |
| 合并走本地非快进合并还是 PR | `core/worktree开发纪律.md`（按 `merge-gate`） |
| 决策沉淀进 memory 的写法 | `core/上下文卫生.md` |
| 什么时候必须升级到完整流程 | `core/00-流程总纲.md` Triage 四问 |
| 哪个是权威实现、怎么查代码事实 | `capability/curated.md`、`capability/graph.md`（按探测启用） |

## 一句话

协作面 = solo 砍掉的是**对齐开销**（Overview / 评审会 / owner），砍不掉的是**复核**——评审门、兼容拍板、测试资产一条不减，因为没有第二个人替你兜。
