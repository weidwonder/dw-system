# Glossary — 领域词汇表（engineering-context/glossary.md）

> **纯词汇表，禁实现细节**。它只回答"这个词在我们业务里指什么"，不回答"它在代码里怎么实现"——实现事实归 card（带 cite），能力映射归 registry。三者分工：**glossary 管说法一致，card 管事实权威，registry 管能力落点**。
> 价值：全团队（人和 AI）对同一概念用同一个词——命名不漂移、文档可检索、AI 生成的代码/文档词汇统一，减少"同一实体多种叫法"制造的相似陷阱。
> 维护：低频、人工。新词在 PRD/spec 评审中出现分歧时立刻收录；含义变更时改条目并在备注记变更日期。条目里出现"表/接口/类名"即为越界，移去 card。
