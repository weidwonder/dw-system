# 升级到 1.6.1（自 1.6.0）

## 结论

**修复伴生 skill `agentic-principle` 的用户级安装路径。** v1.6.0 把 Codex 侧装到了 `~/.agents/skills/` —— 那不是 Codex 的用户级入口（`.agents/` 只用于**项目级**），正确位置是 `~/.codex/skills/`。本版起装到 `~/.claude/skills/` 与 `~/.codex/skills/`。流程、模板、文档约定均无变化。

## 需要的动作

- **删掉旧位置的陈旧副本**（如果 v1.6.0 给你装过）：

  ```bash
  rm -rf ~/.agents/skills/agentic-principle
  ```

  安装器检测到它时会打印同样的提示，但**不会自动删**你家目录里的东西。留着它没有直接危害，只是一份 Codex 读不到、也永远不会被更新的副本。
- **无需其他动作**：重跑安装器即可把 `agentic-principle` 装到正确位置；本地是 symlink 或 git 工作区时仍然只报告版本、不覆盖。

## 顺带修正

- README 的「方式 C：全局安装一次」里，两个主 skill 的 Codex 全局安装路径同样由 `~/.agents/skills/` 改为 `~/.codex/skills/`。项目级安装路径 `<项目>/.agents/skills/` 不变。
