# 升级到 1.9.0（自 1.8.0）

## 结论

**安装器多做一段 codegraph：保持最新 → 接线到 agent → 给本项目建索引。** codegraph（`github.com/colbymchenry/codegraph`）是本地代码知识图谱 CLI，给 AI 可查询的代码事实（`explore` / `impact` / `callers`），随文件变更 auto-sync。本版起每次安装：

- 本机没有就 `npm install -g @colbymchenry/codegraph`；已有就用它自己的 `codegraph upgrade` 检测并升级，已是最新则跳过。
- 接线：`codegraph install --target=auto --location=local --yes`，**默认项目级**，只影响本项目。
- 建索引：`.codegraph/` 不存在时执行 `codegraph init`（大仓库要几分钟）；已存在则跳过。
- 目标项目 `.gitignore` 标记块新增 `/.codegraph/`（索引是本机 SQLite 库，不入库）。
- 这一段的任何失败都只降级为警告，skill 安装不受影响。用 `--no-codegraph` 整段跳过。

流程、模板、skill 内容与目录约定均无变化；团队版找权威事实仍以 card + cite 为准，codegraph 只是找现状代码的通道。

## 需要的动作

- **Claude Code 用户**：重启后才会加载 codegraph MCP server；项目级 `.mcp.json` 首次使用需在弹窗里批准。
- **Codex CLI 用户**：Codex 没有项目级 MCP 配置，项目级模式下它**不会**被接线。需要时手动执行（影响你所有项目）：

  ```
  codegraph install --target=codex --location=global --yes
  ```

  或安装时直接用 `--codegraph-location=global` 一次性全局接线。
- **不想要这套的**：加 `--no-codegraph` 重跑安装器；已装到全局的 CLI 用 `codegraph uninstall` 自行移除（安装器不代劳卸载）。
- `npm install -g` 失败（多为全局目录权限或 PATH 未包含 npm 全局 bin）时，安装器只警告并打印手动命令，按提示装完重跑即可。
