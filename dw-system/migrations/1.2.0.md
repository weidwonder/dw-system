# 升级到 1.2.0（自 1.1.0）

## 结论

**无破坏性变更。** 安装器新增：在目标项目 `.gitignore` 幂等追加已安装 skill 目录与版本 stamp 的忽略规则（`# ai-dev-system:gitignore:start/end` 标记块），避免本体系随目标仓库提交。本次升级安装会自动写入该块。

## 需要的动作

- **此前已把 skill 提交进目标仓库的项目**：`.gitignore` 对已跟踪文件不生效，需手动移出索引（保留本地文件）：

  ```bash
  git rm -r --cached .claude/skills .agents/skills
  git commit -m "chore: stop tracking ai-dev-system skills"
  ```

  若这两个目录下还有你自己的 skill 想继续入库，只 `--cached` 移除 `ai-prd/`、`ai-dev-workflow/` 和 `ai-dev-system.version` 即可。
- **skill 从未入库的项目**：无任何动作。

## 行为变化知会（自动生效，无需迁移动作）

- 忽略规则按具体 skill 名逐条写（如 `/.claude/skills/ai-prd/`），不会整目录忽略 `.claude/skills/`，你自己的 skill 不受影响。
- 重复安装只替换标记块内内容，不会重复追加；撤销只需删除该标记块。
