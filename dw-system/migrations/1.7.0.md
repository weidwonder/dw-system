# v1.7.0 迁移指南

## 发生了什么

安装器现在会在交互安装时询问 Codex 冲突技能的处理方式：

- 项目级 `AGENTS.md` 自动触发约束（默认，不影响其他项目）；
- 全局卸载 Codex superpowers（影响当前用户的所有项目）。

自动化安装默认仍选择项目级约束。只有传入 `--codex-conflicts=uninstall` 才会执行全局卸载。

## 需要的动作

- 若希望保持原有项目隔离行为，无需操作。
- 若希望卸载全局 Codex 插件，确认本机 `codex` CLI 可用后重新执行安装器并选择全局卸载，或显式传入 `--codex-conflicts=uninstall`。
- 全局卸载完成后需要重启 Codex，使插件状态在新会话生效。
