# 升级到 2.13.0（自 2.12.x）

## 结论

安装器现在会决定 **`docs/` 与 `engineering-context/` 要不要提交进 git**，并把结果记进
`.gitignore` 的 `# ai-dev-system:gitignore:start/end` 标记块。

- 交互安装：问一次，**回车即"不提交"**（把 `/docs/` 与 `/engineering-context/` 写进该块）。
- `--yes` / CI / npx 自动安装：取同一个默认值 `no`，一次落定、之后不再问。
- 结果以 `# ai-dev-system:project-docs-in-git=yes|no` 记在块内，重装沿用、不再询问。

**这两个目录本来是随仓库提交的**，升级后重装一次就会被忽略——这是本次唯一需要你确认的变化。

## 需要的动作

- **希望这两个目录继续入库的项目**：升级安装时选 `y`，或直接跑

  ```bash
  npx --yes git+https://github.com/weidwonder/ai-dev-system.git . --docs-in-git=yes
  ```

  块内会只留一行 `project-docs-in-git=yes`，不写任何忽略规则。
- **已经装成"不提交"、事后想改回入库的项目**：用同一条 `--docs-in-git=yes` 重跑一次即可，
  它会就地改写块内的记号并删掉那两条忽略规则。
- **`.gitignore` 里已有你自己写的 `docs/` / `engineering-context/` 忽略规则的项目**：无任何动作，
  安装器既不发问也不接管你的规则。
- **其余项目**：无动作，接受默认的"不提交"即可。

## 行为变化知会（自动生效，无需迁移动作）

- `.gitignore` 对**已跟踪**的文件不生效：已经提交过的 `docs/` 内容不会消失，只是此后新增的文件不再被 `git add` 收进去。
  要真正停止跟踪，另跑 `git rm -r --cached docs engineering-context`。
- 标记块的其余各行（skill 目录、版本 stamp、`.codegraph/`）一个字节都没改，撤销本特性只需删掉块内那一行记号与两条路径。
