# 测试场景覆盖度台账

> 固定文件名的单一账本：`docs/report/测试场景覆盖度.md`。不按 `<feature>-<report-type>-report.md` 拆分（`dw-doc-governance` 的 `文档治理.md` §硬规则 的两个固定文件名例外）。
> 维护规则见 `测试资产纪律.md` §3。**这份台账的主要用途是攒够一批后向用户索要真实素材**，所以"缺什么素材"一列要写成用户照着就能找到的东西。
> 更新时机：写完 test-spec 后 / 新增或淘汰样本后 / bug 修复归档时 / 需求准出复核时。
> **这是当前状态表，不是流水账**：同一场景只有一行，状态变化就地改；场景废弃时移入文末「已淘汰场景」，不留在主表、也不删除。
> **示例行 MUST 在填写时删除**：本模板产出的是固定文件名的**真实台账**（`docs/report/测试场景覆盖度.md`），

> 每张表都标了哪几行是示例；只留含 `【】` 的空骨架行，按自己项目填。
