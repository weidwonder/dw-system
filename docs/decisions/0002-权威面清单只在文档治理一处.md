# 0002 权威面清单只在文档治理一处

状态：现行 ｜ 日期：2026-08-19（2.3.0）

## Context

"权威面"的类目同时被两个地方需要：写文档时填 `authority_refs`，评审门文档轴盘点本次触碰了什么。

## Decision

类目清单只在文档治理〈归档触发〉第 1 步列一次；填字段的那一节只放指针。

## Alternatives Considered

- **两处各列一份、靠人保持一致**：试过，两份很快写岔——一份有"对外契约与字段枚举"，另一份有"废弃标记""兼容窗口"，评审时没人知道以哪份为准。

## Consequences

这是"一个事实只有一个家"在本体系里最早的一次落地；3.0.0 把它提升为总纲。
