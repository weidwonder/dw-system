# 业务域卡 — dw-system › 安装主干

## 职责
把指定版本的 skill 分发包装进目标项目的 `.claude/skills/` 与 `.agents/skills/`，并处置版本戳、迁移指南、`.gitignore` 标记块与 docs 入库决定、Claude Code / Codex 的冲突插件、入口文件的软链接。

## 权威实现与对外接口

| 能力 / 入口 | 权威实现（cite） | 约束 |
|---|---|---|
| 默认安装源与默认版本 | `install.mjs#DEFAULT_REPO`、`install.mjs#DEFAULT_REF` | 默认 ref 是 `v<自带 VERSION>`（`install.mjs#SELF_VERSION`），只有读不到 `VERSION` 才退回 `install.mjs#FALLBACK_REF`。包版本与 skill 源版本由此绑定；没有这条，版本戳与实际装到的内容会对不上。 |
| 取源 | `install.mjs#acquireSource` | 两条失败语义不对称：**默认推出的 tag** 取不到 → 告警并回退 `main`，MUST NOT 静默；**用户显式 `--ref`** 取不到 → 硬失败，MUST NOT 回退成别的版本。Git 不可用单独报错。 |
| 目标零改动保证 | `install.mjs#discoverSkills` | 源先浅克隆到系统临时目录，确认有含 `SKILL.md` 的目录之后才读写目标项目；下载或校验失败时目标零改动。临时目录在成功、取消、预演、异常四种收尾下都清理；`--source-dir` 走本地目录，不清理。 |
| 中止点的先后 | `install.mjs#main` | 所有可能中止的解析（settings JSON、入口软链接、标记块字段、Codex 插件清单）MUST 发生在覆盖任何 skill 之前。Codex 全局卸载排在用户确认之后、目标项目落盘之前；卸载失败则目标保持原样。 |
| 复制与版本戳 | `install.mjs#copySkills`、`install.mjs#VERSION_STAMP` | 每个 skill 先删后整目录复制，装到 `.claude/skills/` 与 `.agents/skills/` 两处，两处各写一份版本戳 `dw-system.version`。 |
| 已装版本判定 | `install.mjs#readInstalledVersion` | 顺序固定：新戳 → 旧名字的戳 → 有 skill 目录而无戳按 `install.mjs#LEGACY_VERSION` → 全新安装。 |
| 迁移指南 | `install.mjs#collectMigrations` | 取 (已装版本, 源版本] 区间内的全部指南，按版本升序**全文**打印；`--dry-run` 同样打印。降级安装时该区间为空，只告警。 |
| `.gitignore` 标记块 | `install.mjs#gitignoreBlock`（起止 `install.mjs#GITIGNORE_START`） | 按 skill 名逐条忽略两处 skill 目录与版本戳，不整目录忽略——否则误伤使用者自己的 skill。`.codegraph/` 无条件写入，使 `--no-codegraph` 与默认安装产出同一个块。 |
| docs 入库决定 | `install.mjs#chooseProjectDocsInGit` | 优先级：`--docs-in-git=yes\|no` > 块内已记的决定 > 块外已有使用者自己的忽略规则（返回 null：不发问、不写记号、不接管）> 非交互（`--yes` / `--dry-run` / 非 TTY）取 `no` > 交互询问，回车 = `no`。交互与非交互 MUST 同一个默认值；否则同一条命令加不加 `--yes` 产出不同的 `.gitignore`。 |
| 决定的记号 | `install.mjs#PROJECT_DOCS_MARK`、`install.mjs#readProjectDocsDecision` | 记号 MUST 写在 `.gitignore` 标记块**内**，读取也只认块内。改主意的唯一入口是显式 `--docs-in-git=`。 |
| Claude Code 冲突插件 | `install.mjs#CLAUDE_CONFLICTS` | 在目标项目级 settings 的 `enabledPlugins` 里设为 `false`：项目级覆盖用户级，只在本项目禁用。默认写 `.claude/settings.local.json`，`--shared` 写 `.claude/settings.json`；合并时不覆盖其他键，数组形态先转 map。 |
| Codex 冲突处置 | `install.mjs#codexGuardBlock`、`install.mjs#assertCodexGuard`、`install.mjs#chooseCodexConflictMode`、`install.mjs#uninstallCodexConflicts` | 默认不动全局插件，只在 `AGENTS.md` 写入并校验约束块（起止 `install.mjs#CODEX_GUARD_START`）。`--codex-conflicts=uninstall` 或交互选择才全局卸载。`--keep=<短名>` 保留该插件，并撤销此前为它写的禁用项与约束块。 |
| 入口软链接 | `install.mjs#resolveLinkTarget`、`install.mjs#assertWritableEntry` | `CLAUDE.md` / `AGENTS.md` 是软链接时逐层解析到实体文件再写（上限 `install.mjs#MAX_LINK_HOPS`，成环报错），链接本身保留；两个入口解析到同一实体只写一次；断链在复制任何 skill 之前报错。 |

## 陷阱项

> 每行一条"这样写会悄悄坏掉"。

- 显式 `--ref` 取不到时回退到 `main` — 使用者点名要的版本被悄悄换成另一个版本；只有安装器自己推出的默认 tag 才允许回退。
- 在源校验通过之前读写目标项目 — 下载失败会留下半装状态；一切目标写入 MUST 排在 `discoverSkills` 确认之后。
- 把 docs 入库记号写在 `.gitignore` 标记块外 — 下一次幂等改写只重写块内，块外那一行成为孤儿，决定随之丢失。
- 用"`.gitignore` 里有没有忽略规则"反推使用者的 docs 入库决定 — 分不开"上次选了提交"与"从没问过"；只认块内记号。
- 给 docs 入库的交互与非交互路径设不同默认值 — 同一条命令加不加 `--yes` 产出不同的 `.gitignore`。
- 整目录忽略 `.claude/skills/` — 使用者自己放在同目录的 skill 会被一起忽略；只许按 skill 名逐条写。
- `--codex-conflicts=uninstall` 是全局卸载 — 影响该用户的所有项目，不是只影响目标项目；默认路径是项目内约束块。
- 全局卸载分支清理入口文件时删软链接或链接指向的文件 — 那个文件可能被两个入口共用；只许删安装器自己建出来的空 `AGENTS.md`。
